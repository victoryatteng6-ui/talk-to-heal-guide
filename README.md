# Your Health Pal

Objective: Create an intuitive and engaging UI for a Voice-Enabled Health Assistant web app.

Specifications:

Homepage:

Design a welcoming interface with a prominent microphone icon for voice activation.

Include a brief description of the app's purpose and a visual cue for voice command usage.

Health Categories:

Create distinct sections/buttons for Triage, First Aid, and Wellness.

Ensure categories are visually appealing and easily navigable.

Chat Interface:

Develop a responsive chat interface that displays user queries and bot responses.

Implement a speech bubble design for clarity and engagement.

Settings:

Allow users to customize voice preferences (e.g., voice speed, language).

Provide options for text size and color themes for accessibility.

Disclaimer:

Include the statement “I’m not a doctor. For medical advice, please consult a healthcare professional.” in a visible area of the UI, ideally on the homepage and chat interface.

Accessibility Features:

Ensure compatibility with screen readers and keyboard navigation.

Use high-contrast colors for better visibility.





Safe Health Categories

Triage:

Assess symptoms and provide guidance on urgency.

First Aid:

Offer basic first aid procedures for common injuries and emergencies.

Wellness:

Provide tips on nutrition, exercise, mental health, and preventive care.
